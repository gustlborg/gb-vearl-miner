# GB Vearl Miner

Experimental miner development based on the Apache-2.0 licensed
[Vearl reference implementation](https://github.com/vearl-verified-compute/vearl).
Independent project; no affiliation with or endorsement by the Vearl team.

This repository contains public project information and is the intended home for
future tested releases. Development sources are maintained separately in a private
repository. No production release is available here yet.

Initial baseline: [Vearl v0.1.0-rc23](https://github.com/vearl-verified-compute/vearl/releases/tag/v0.1.0-rc23).
The first development target is Linux x86_64 with NVIDIA Ada GPUs.

Work in progress: reproducible benchmarks, CPU/GPU correctness checks and CUDA
launch-overhead reduction. No speedup over the reference or third-party miners is
claimed at this stage.

For current official software and network instructions, use the
[official releases](https://github.com/vearl-verified-compute/vearl/releases) and
[participation guide](https://vearl.org/participate/).

The upstream project is testnet software without an external audit. Testnet tokens
have no monetary value. Benchmark results, when published, will distinguish local
throughput from work accepted by a pool.
